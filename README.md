# רדאר איתותים

מערכת איתותים לטווח קצר על BTC, ETH, SOL וזהב (PAXG), עם נתוני Binance חיים.

- **index.html** — הדשבורד (גרף, ציון, בדיקה לאחור, אופטימיזציה).
- **bot.js + engine.js** — בוט טלגרם שסורק 24/7 ושולח:
  - 🟢/🔴 איתות חדש עם כניסה, סטופ, יעדים, סיבות, והביצועים ההיסטוריים של איתות כזה.
  - ✅/❌ דיווח כשהעסקה הגיעה ליעד או לסטופ, ומעקב ביצועים חי מצטבר.
  - פקודות: `/start` חיבור, `/status` מצב כל הנכסים, `/stop` הפסקה.
- הבוט מסנן איתותים שבהיסטוריה של אותו נכס וטווח היו בתוחלת שלילית.

הכל רץ בחינם על GitHub. אין שרת לתחזק.

---

## התקנה (כ-10 דקות, פעם אחת)

### 1. צור בוט בטלגרם
1. בטלגרם חפש **@BotFather** ושלח `/newbot`.
2. בחר שם (למשל `Radar Shlomo`) ושם משתמש שמסתיים ב-`bot`.
3. תקבל **טוקן** שנראה כך: `7123456789:AAH...`. שמור אותו. אל תשתף אותו עם אף אחד.

### 2. צור מאגר ב-GitHub
1. היכנס ל-github.com (או הירשם בחינם).
2. לחץ **+** למעלה ← **New repository**. שם: `radar`. סמן **Public**. לחץ **Create repository**.
3. לחץ **uploading an existing file**, גרור את כל הקבצים מהתיקייה שחילצת מה-zip, ולחץ **Commit changes**.

### 3. הוסף את קובץ ההפעלה האוטומטית
תיקיות שמתחילות בנקודה לא תמיד עולות בגרירה, לכן יוצרים אותו ידנית:
1. במאגר לחץ **Add file** ← **Create new file**.
2. בשם הקובץ הקלד בדיוק: `.github/workflows/radar.yml`
3. פתח את הקובץ `workflow-radar.yml` מהתיקייה, העתק את כל התוכן והדבק.
4. לחץ **Commit changes**.

### 4. הכנס את הטוקן בצורה מאובטחת
1. במאגר: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
2. Name: `BOT_TOKEN`. Secret: הטוקן מ-BotFather. לחץ **Add secret**.

### 5. הפעל
1. בטלגרם פתח את הבוט שלך ושלח `/start`.
2. במאגר: לשונית **Actions**. אם מופיעה הודעה, לחץ **I understand… enable them**.
3. בחר **Signal Radar** ← **Run workflow** ← **Run workflow**.
4. תוך דקה תקבל בטלגרם הודעת חיבור ומצב של כל הנכסים. מעכשיו זה רץ לבד כל 5 דקות.

### 6. (רשות) דשבורד באתר קבוע
1. **Settings** ← **Pages** ← Source: **Deploy from a branch** ← Branch: `main`, תיקייה `/ (root)` ← **Save**.
2. אחרי דקה תקבל כתובת כמו `https://שם-המשתמש.github.io/radar/`.
3. ערוך את `config.json` במאגר (אייקון העיפרון) והדבק את הכתובת ב-`siteUrl`. מעכשיו כל איתות בטלגרם יכלול קישור לדשבורד.

## הגדרות (`config.json`)

| שדה | מה זה | ברירת מחדל |
|---|---|---|
| `assets` | נכסים לסריקה | BTC, ETH, SOL, PAXG |
| `timeframes` | טווחים: `5m`, `15m`, `1h` | `15m`, `1h` |
| `params.th` | סף ציון לאיתות (גבוה יותר = פחות איתותים, סלקטיביים יותר) | 55 |
| `params.sl` | סטופ בכפולות ATR | 1.5 |
| `params.rr` | יחס רווח/סיכון ליעד | 2 |
| `params.htf` | חובה אישור מגמה בטווח גבוה | true |
| `overrides` | פרמטרים לנכס וטווח מסוים, למשל `{"PAXGUSDT\|15m": {"th": 60, "rr": 1.5}}` | ריק |
| `onlyPositiveEdge` | לא לשלוח איתות שבהיסטוריה היה בתוחלת שלילית | true |

**טיפ:** פתח את הדשבורד, בחר נכס וטווח, לחץ "מצא פרמטרים טובים". אם ההגדרות החזיקו גם בתקופת הבחינה, העתק אותן ל-`overrides`.

## שאלות

**למה לא `5m`?** GitHub מריץ משימות מתוזמנות בערך כל 5 דקות, ולפעמים באיחור של כמה דקות. בטווח 15 דקות ושעה זה לא משנה. לטווח 5 דקות עדיף להריץ ברציפות (ראו למטה). אם הודעה מגיעה באיחור, כתוב בה בכמה דקות.

**הבוט לא שולח כלום?** זה תקין כל עוד אין איתות. הבוט שולח רק כשיש איתות חדש, ובממוצע יש כמה ביום. שלח `/status` כדי לוודא שהוא חי (התשובה תגיע עד הריצה הבאה, כלומר תוך כ-5 דקות).

**שגיאה ב-Actions?** לחץ על הריצה האדומה וקרא את הלוג. "חסר BOT_TOKEN" = הסוד לא הוגדר בשם המדויק. שגיאת HTTP 451 מ-Binance = חסימה אזורית; נסה להריץ שוב, ואם זה חוזר עבור לריצה רציפה מהמחשב.

**GitHub השהה את המשימה?** GitHub משהה משימות מתוזמנות במאגר שאין בו פעילות 60 יום, ושולח מייל עם כפתור להפעלה מחדש.

**ריצה רציפה (מיידית, כולל 5m) מהמחשב או משרת:**
```
BOT_TOKEN=הטוקן_שלך node bot.js --loop
```
דורש Node 18 ומעלה. ב-Render או Railway: Start command `npm start`, ומשתנה סביבה `BOT_TOKEN`. אל תריץ את שני המצבים במקביל עם אותו טוקן.
